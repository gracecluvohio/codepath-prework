App idea:
I'd like to build a to-do list app that schedules time for you to work on your tasks as you enter them in the app. I'd like for there to be a function where it will ask you questions such as your preferred time to work, times to rest, what regularly scheduled meetings/classes you have to attend, etc. so that it can schedule your tasks around that. It'd also be nice to be able to connect to your Google Calendar so that you don't have to manually enter your class/meeting times.
